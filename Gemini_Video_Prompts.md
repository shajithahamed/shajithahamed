1. In Gemini, start a video and **upload the poster photo of the man** as the reference image, so every clip shows the same person.
2. Copy the **character + setting block** below, then add one **scene prompt** after it.
3. Make every clip **vertical (9:16)**, about **8 seconds**.
4. Ask for **no on-screen text, no logos and no subtitles**. I add all text afterwards, so it is spelled correctly. AI video often misspells Tamil, for example "சிகாளனா" in your reference.
5. Download each clip and name it by scene number (`scene1.mp4`, `scene2.mp4` …).
